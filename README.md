# StepSpeak English

AIと**声で**会話しながら英語を練習するWebアプリです。マイクに向かって英語で話すと、AIが英語で返事を読み上げ、言い方の添削を日本語で返します。

## できること

- **声で会話**: マイクをタップして話す → AIが音声で返事。相手の英文は最初は隠れていて、聞き取れなかったときだけタップして表示(設定で常時表示にもできます)
- **5段階のレベル**(Step 1 入門 〜 Step 5 上級)と **8つのシーン**(フリートーク、自己紹介、カフェ、レストラン、旅行、買い物、仕事、面接)
- **その場で添削**: 話した文がより自然な言い方と日本語の解説つきで返ってきます。お手本は音声でも聞けます
- **ヒント**: 返事に詰まったら、次に言える例文を2つ表示
- **日本語で言う**: 英語が出てこないときは日本語で話すと、英語での言い方を教えてくれます
- **ハンズフリー**: 相手が話し終えたら自動で聞き取りを開始
- **ふりかえり**: 会話を終えると、よかった点・直したい表現・次に使いたいフレーズをまとめます

## 起動方法

Node.js 20.12 以上と、Anthropic の APIキーが必要です。

```bash
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env
npm start
```

ブラウザで http://localhost:3000 を開きます。

| 環境変数 | 説明 | 既定値 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Anthropic の APIキー(必須) | – |
| `CLAUDE_MODEL` | 会話に使うモデル | `claude-opus-5-5` |
| `PORT` | ポート番号 | `3000` |

## 対応ブラウザ

音声認識と読み上げにはブラウザ標準の Web Speech API を使っています。

- **Chrome / Edge / Safari**: 声で会話できます
- **Firefox など**: 音声認識が使えないため、文字入力での練習になります

マイクは `https://` か `localhost` でしか使えません。スマホから使う場合は HTTPS で公開してください。

## 公開するときの注意

ログイン機能や利用回数の制限はありません。インターネットに公開すると誰でもあなたのAPIキーで会話できてしまうので、公開する場合は認証やレート制限を追加してください。

## 構成

- `server.js` — Express サーバー。`/api/chat`(会話の1ターン)と `/api/review`(ふりかえり)で Claude API を呼びます
- `public/` — 画面(ビルド不要の HTML / CSS / JavaScript)
